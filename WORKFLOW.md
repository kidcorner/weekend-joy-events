# 🚀 Weekend Joy Events - Workflow Guide

## Quick Start: Updating Your Website

Your website is live at: **https://kidcorner.github.io/weekend-joy-events/**

---

## 📝 How to Update Your Website

### Step 1: Make Your Changes
- Edit any files in your project (HTML, CSS, JS, images, etc.)
- Test locally at `http://localhost:8000` if needed (run `python3 -m http.server 8000`)

### Step 2: Commit Your Changes
1. Open **GitHub Desktop**
2. You'll see your changed files listed on the left side
3. Write a descriptive commit message:
   - Examples:
     - "Updated hero colors to purple"
     - "Added new event page"
     - "Fixed mobile menu styling"
     - "Updated images in gallery"
4. Click **"Commit to main"**

### Step 3: Push to GitHub
1. Click **"Push origin"** button (or "Sync" if shown)
2. This uploads your changes to GitHub

### Step 4: Wait for Deployment
- GitHub Pages automatically rebuilds your site
- Wait **1-2 minutes**
- Refresh your live website to see changes!

## 💡 Best Practices

### Commit Messages
Write clear, descriptive messages:
- ✅ Good: "Updated navbar colors and added animations"
- ✅ Good: "Fixed mobile responsive layout"
- ❌ Bad: "changes"
- ❌ Bad: "update"

### When to Commit
- Commit after completing a feature or fix
- Commit when you've tested your changes
- Don't commit broken code
- Commit frequently (small commits are better than huge ones)

### Testing Before Pushing
- Test your changes locally first
- Check on different screen sizes if possible
- Make sure images load correctly
- Verify links work

## 🔄 Common Tasks

### Adding a New Page
1. Create new HTML file (e.g., `new-event.html`)
2. Add links to it from other pages
3. Commit: "Added new event page: new-event.html"
4. Push

### Updating Styles
1. Edit `styles.css` or `event-pages.css`
2. Test locally
3. Commit: "Updated button styles and colors"
4. Push

### Adding Images
1. Add image to `assets/images/` folder
2. Update HTML to reference the image
3. Commit: "Added new images for gallery"
4. Push

### Fixing Bugs
1. Fix the issue in your code
2. Test the fix
3. Commit: "Fixed mobile menu not closing"
4. Push

## 🆘 Troubleshooting

### Changes Not Showing?
- Wait 2-3 minutes (GitHub needs time to rebuild)
- Hard refresh your browser (Cmd+Shift+R on Mac, Ctrl+Shift+R on Windows)
- Check GitHub Pages settings: Settings → Pages → should show "Deployed from main"

### Can't Push?
- Make sure you're connected to the internet
- Check if GitHub Desktop shows any error messages
- Try clicking "Fetch origin" first, then push again

### Want to Undo Changes?
- In GitHub Desktop, go to History tab
- Right-click on a previous commit
- Select "Revert this commit"
- Push the revert
